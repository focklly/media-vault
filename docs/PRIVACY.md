# 权限与隐私说明（Privacy）

> 一句话：扩展不收集任何数据、不内置统计、不发远程配置；所有文件只存在你的电脑和你主动配置的存储站点。

---

## 1. 数据流向

```text
你浏览的网页 ──(抓取图片/视频原文件)──▶ 扩展 Service Worker
                                            │
                                            ├──▶ 本地 IndexedDB（个人空间，唯一主库）
                                            └──▶ 你配置的上传目标（GitHub / R2 / WebDAV / HTTP 图床）
```

不存在「扩展服务器」。代码中没有埋点、没有 `fetch` 到非用户配置地址的调用。

---

## 2. 各项权限的用途

| 权限 | 具体用途 | 不授予会怎样 |
| --- | --- | --- |
| `host_permissions: http://*/*, https://*/*` | ① 在网页注入悬浮球/悬停按钮；② 跨域抓取图片视频原文件；③ 访问你配置的图床/网盘 | 无法自动扫描与一键入库 |
| `storage` | 保存设置（含适配器配置） | 设置无法持久化 |
| `unlimitedStorage` | 个人空间可能存数 GB 媒体，普通配额会被挤掉 | 大图库可能写失败 |
| `contextMenus` | 右键图片/视频「存入影图管家」 | 少一个入口 |
| `notifications` | 入库/上传完成通知 | 无提示，功能不受影响 |
| `tabs` | 打开/聚焦个人空间页、读取当前页标题 | 图库打开体验变差 |
| `scripting` | 保留按需注入能力 | 预留，未强依赖 |
| `downloads` | 从图库导出文件 | 导出功能不可用 |

**没有申请**：`webRequest`（不监听全部流量）、`cookies`（不直接读 Cookie 表）、`history`、`bookmarks`、`identity`。

---

## 3. 本地存了什么

| 存储 | 内容 | 位置 |
| --- | --- | --- |
| IndexedDB `mediavault` | 媒体元数据 + 原始文件 + 缩略图 | 浏览器 profile 目录 |
| `chrome.storage.local` | 设置、适配器 Token/密码、悬浮球位置 | 浏览器 profile 目录 |

清理方式：设置 → 数据与备份 → 「清空全部数据」；或 `chrome://extensions` 移除扩展（会连同 IndexedDB 一起删除）。

---

## 4. 密钥风险（重要）

浏览器扩展**没有**安全存储（没有 Keychain / Keystore 等价物）。适配器的 Token、Secret、应用密码以明文存在 `chrome.storage.local`：

- 仅本机、仅该扩展可读（页面 JS 读不到）；
- 但任何能访问你电脑的人/恶意程序都可能读走；
- 因此：**不要在公共或共享电脑保存 Token**；为每个站点使用最小权限、可单独撤销的 Token；怀疑泄露立即撤销重发。

---

## 5. 第三方站点

上传只发生在你点击「上传」或显式开启「入库后自动上传」时。文件会离开你的电脑进入对应服务商，适用其隐私政策与内容政策。扩展无法控制这些站点的可用性、外链策略或删除行为。

---

## 6. 未成年人 / 内容合规

扩展只是「把用户看到的媒体存到用户指定的位置」，不做内容识别、不做分发、不上传索引。请遵守目标网站的服务条款与版权规则：仅保存你有权保存的内容。

---
