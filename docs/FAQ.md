# 常见问题（FAQ）

## 安装与加载

**Q：加载时提示「清单文件缺失或不可读取」？**
A：选择的是仓库根目录吗？目录里必须能直接看到 `manifest.json`。不要选 `src/`。

**Q：改了代码没生效？**
A：两步都要做：`chrome://extensions` 点扩展卡片的刷新；再刷新目标网页（content 只在页面加载时注入）。

**Q：支持 Firefox 吗？**
A：v1.0.0 只针对 Chrome / Edge 116+。Firefox 的 MV3 在 `browser.*` 命名空间、后台脚本形态上有差异，属于 P2 待办。

## 页面浮层

**Q：右下角没有悬浮球？**
依次检查：① 扩展是否启用；② 设置 → 通用 → 「启用页面浮层」是否打开；③ 该站点是否在「排除站点」里；④ 当前页是否是 `chrome://`、扩展商店等禁止注入的页面。

**Q：悬停在图片上不出现按钮？**
① 图片显示尺寸小于「悬停按钮最小边长」（默认 120px）；② 设置里关掉了悬停按钮或视频按钮；③ 图片在 iframe 里（当前只处理顶层文档）。

**Q：按钮挡住了页面按钮/播放器？**
拖动悬浮球换个位置；或在设置里关掉「视频也显示悬停按钮」，只对图片生效。

**Q：扫描数量比页面看到的图片少？**
默认过滤了小于 80px 的图片，且只取可访问的 http/data 链接（blob 地址在悬停时才即时抓取）。可在设置里调低最小边长、调高单页上限。

**Q：悬浮球位置为什么所有网站共用？**
位置存在全局设置里，属于刻意设计（保持一致操作习惯）。如需按站点记忆，可在 `content.js` 的 `persistBallPosition` 里加 hostname 维度。

## 入库与存储

**Q：点「存入个人空间」后，文件在哪？**
在浏览器扩展的 IndexedDB 里，不是普通文件夹。查看：扩展图标 → 打开图库；或 DevTools → Application → IndexedDB → `mediavault`。

**Q：为什么有的条目显示「仅链接」？**
原文件抓取失败（防盗链、需要登录、跨域限制、超过单文件上限）。这类条目保留来源链接，可预览时尝试直连源站，但不能上传外部站点（没有本地副本）。

**Q：视频入库后没有封面？**
当前只在页面提供 `poster` 时生成封面；SW 无法解码视频帧。P0 待办是在页面侧 canvas 截帧。

**Q：能存 m3u8 视频吗？**
只保存播放地址，记录标记「流媒体」，不做整片下载。整片下载需要 ffmpeg.wasm 或外部工具（P1/P2）。

**Q：个人空间很占磁盘吗？**
只存你主动入库的文件。设置页可看到占用；图库支持批量删除。

**Q：换电脑/重装浏览器数据还在吗？**
不在。IndexedDB 属于单个浏览器 profile。可导出清单 JSON 备份元数据（不含文件本体），文件请从图库「导出文件」或依赖外部站点。

## 上传

**Q：测试连接通过，但上传失败？**
看 `item.remote.error`（图库卡片会标红）。常见：GitHub 413（文件过大）、S3 403（签名/权限）、WebDAV 409（目录不存在）、图床 401（Token）。

**Q：上传成功后链接打不开？**
私有仓库 / 私有桶 / 需要登录的 WebDAV 都会这样。配置公开访问域名（`publicBase`）或改用公开仓库。

**Q：开启「自动上传」会不会很耗流量？**
每个入库文件都会完整上传一次。图片问题不大，视频建议保持关闭，在图库里挑选后再上传。

**Q：支持断点续传吗？**
v1 不支持（S3 分片在 P1）。大文件上传时请保持页面/扩展不被终止。

## 数据与安全

**Q：Token 存在哪里？安全吗？**
`chrome.storage.local` 明文，仅本机、页面 JS 读不到。公共电脑不要保存；用最小权限、可撤销的 Token。

**Q：扩展会把我的图片传到你们服务器吗？**
不会。没有「我们服务器」。只有你配置的上传目标会收到文件。

**Q：怎么彻底清除数据？**
设置 → 数据与备份 → 清空全部数据；或在 `chrome://extensions` 移除扩展。已上传到外部站点的文件需到对应站点删除。

**Q：能同时用多个上传目标吗？**
v1 一次上传选一个目标（图库预览弹窗里可切换）。多目标同时上传属于 P1。
