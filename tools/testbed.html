影图管家 · 本地测试台

用途：安装扩展后打开本页，逐项验证拾取能力。
1. 悬停任意大图/视频 → 光标旁应出现「存入个人空间」；单击入库，Shift+单击直接上传。
2. 右下角悬浮球拖动、点开菜单 → 「全部存入」「查看媒体清单」应能列出下面所有媒体。
3. 小图标（24px）默认不应出现悬停按钮（受「悬停按钮最小边长」控制）。
4. 本页视频/图片均为公开示例源，若某个源被墙或防盗链，恰好可以验证「仅链接」降级逻辑。

1. 标准 img（src / srcset）

data URI · 800×600 · 应出现按钮

srcset · 应抓取最大尺寸（800w）

24×24 · 不应出现悬停按钮，且不进清单

2. 懒加载图片（data-src）

1.2 秒后把 data-src 写进 src，再点「重新扫描」应能抓到

CSS background-image · 依赖「扫描 CSS 背景图」开关

3. 视频

标准 video + 两个 source + poster · 悬停应出现「存入个人空间」，封面取自 poster

视频直链（.mp4）

a[href$=.mp4] · 依赖「收集视频直链」开关

4. 视频清单 / 流媒体

本页不含 m3u8 示例（需要真实 CDN 地址）。任意视频网站打开播放器后，悬浮球菜单里应能看到带「流媒体」标记的条目—— 这类地址扩展只保存播放地址，不做整片下载，属于设计上的明确限制。
